ALGORITHM
--------------------------------------------------------------------------------
TEA (Tiny Encryption Algorithm), the classic 64-bit block cipher.
  * 32 rounds, delta = 0x9E3779B9.
  * Decrypt starts sum at 0xC6EF3720 (= delta*32) and does sum += 0x61C88647
    (= -delta) each round.
  * Block = two 32-bit words, LITTLE-ENDIAN.
  * Round function (decrypt):
        v1 -= ((v0<<4)+k2) ^ (v0+sum) ^ ((v0>>5)+k3)
        v0 -= ((v1<<4)+k0) ^ (v1+sum) ^ ((v1>>5)+k1)
Mode: CBC. The engine prepends an 8-byte per-record IV to the ciphertext,
TEA-CBC-decrypts the whole thing, then discards the IV plaintext block.
Because it is CBC, blocks 2..n depend ONLY on ciphertext, so they decrypt
exactly even without the IV; only each record's first 8 bytes need the IV.

.clb PER-RECORD IV (fn @0x140064fd8) -- fully reversed
--------------------------------------------------------------------------------
IV = word24 || word23 (little-endian), derived from:
  w15 = a per-line counter (record index; stored+incremented at [obj+0x24]).
  w7  = a byte constant within a file (from context bytes + trailing chars of a
        context string). Recovered per-file by a 256-way brute that maximises
        first-block printability -- unambiguous; observed w7 == 233 (= 0xE9,
        also the SVCdec "method 3" z constant).
Formula (see decrypt_modern.py::clb_iv):
  a   = (w7+2)*(w15+1)*(w15+3)
  w24 = (w7+1)*(w15+2) + a
  r   = w7 % (w15+1);  w8 = r if r!=0 else w15 % (w7+1)
  w23 = (w7+3)*(w7+1)*(w15+2) + w8
  if w24 < 0xffff: w24 = (w24<<16) + (w15+4)*(w7+3)*(w7+1)*(w15+2)
  if w23 < 0xffff: w23 = (w23<<16) + (w15+1)*(w15+2)*(w15+3)
  (all arithmetic mod 2^32)
